**The Printer Apology** — the note an office printer would write:

> Sorry I need cyan to print black. I am not broken, I am holding your black ink hostage for a friend.

100 characters, one line. It won a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
